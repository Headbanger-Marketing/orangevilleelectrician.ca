Before work begins

Finish each phase so it stands complete on its own.

Take a detached house with an attached garage. Its garage lights and receptacles can share circuits with rooms inside, so a first phase may reach both, while the run between panel and garage may carry work held for a later budget.

Ask each contractor to write every phase as a finished scope with its own notification, its own record and a clear stopping point. Keep each stage's paperwork together so a later contractor can see what was done and what remains.

Is it sensible to stage a project when money arrives in stages?

Yes, if each phase is a complete, safe installation on its own. Ask the contractor to describe what each stage includes, what it leaves untouched and which later stage depends on it, then get that in writing.

What should a quote state so phased proposals can be lined up?

Each quote should list what its phase includes, what it assumes a later phase will cover and who files the ESA notification. Compare quotes by scope rather than total, and check that no phase repeats work another already covers.

What paperwork should survive once a stage of work wraps up?

Keep the written scope, the invoice, any ESA notification paperwork and photos of labels and equipment from the outside. A dated folder for each phase helps the next contractor see exactly what was changed.

Can a garage be wired in a later phase than the house?

It can, if the first phase leaves the route and the panel position clear for it. Ask the contractor whether garage circuits would need their own supply path or could join existing ones, and what that choice changes for the later phase.

Does sending this form commit anyone to a stage of work?

The form commits nobody: it is collected as an enquiry and reviewed. The site offers guides, with no hand in visits or prices, nor in electrical work. A provider or Licensed Electrical Contractor you deal with confirms separately its identity and licence, then scope and price, then timing. Check that licence through ESA before agreeing to any phase.
